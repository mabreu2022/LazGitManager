# LazGitHubIntegration

Plugin oficial e nativo de integração entre o **Lazarus IDE** e o ecossistema **Git / GitHub**.

---

## 🚀 Status da Instalação
* ✅ **Pacote compilado com sucesso** (FPC 3.2.2 / Lazarus 3.0+).
* ✅ **Instalado no Lazarus**: O executável `C:\lazarus\lazarus.exe` foi recompilado com o pacote integrado.
* ✅ **Bibliotecas OpenSSL Configuradas**: `libssl-1_1-x64.dll` e `libcrypto-1_1-x64.dll` instaladas em `C:\lazarus` para comunicação HTTPS TLS nativa.

## ⚡ Atalhos e Acessos Rápidos no Lazarus
* **Painel Dockable Git & GitHub:** Pressione `Ctrl + Alt + G` ou acesse o menu **Exibir > Git & GitHub Manager**.
* **Commit do Projeto Ativo:** Acesse **Projeto > Git Commit Active Project...**.
* **Credenciais e Opções do Git:** Acesse **Ferramentas > Opções > Ambiente > GitHub Integration** (ou pelo botão **Settings...** no painel `Ctrl+Alt+G`).
